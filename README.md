# 🎬 Video Hub & Streaming Web App

An all-in-one Video & Music Streaming Web Application built with **Node.js**, **Express**, **HTML5/CSS/JavaScript**, and **Google Sheets API** as a backend database.

## 📁 Project Structure

```text
video-hub/
├── .env                # Secret environment variables (DO NOT COMMIT)
├── index.html          # Frontend single page web app
├── server.js           # Backend Express server & API routes
├── package.json        # Node.js dependencies and scripts
└── README.md           # Documentation
